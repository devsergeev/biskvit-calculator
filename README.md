# 🍰 Бисквит-калькулятор

Вводишь вес яиц в граммах — калькулятор пересчитывает все остальные ингредиенты.
Оба варианта семейного рецепта: ванильный и шоколадный, плюс опция «пряный»
(корица, бадьян). Рецепт масляного бисквита «в одну чашу», с содой и лимонной
кислотой вместо разрыхлителя.

## Как открыть

- Онлайн (GitHub Pages): **https://devsergeev.github.io/biskvit-calculator/**
- Локально: просто открыть `index.html` двойным кликом в любом браузере.
  Никакой установки не нужно — всё в одном файле.

## Пропорции (на 100 г яиц)

| Ингредиент | Ванильный | Шоколадный |
|---|---|---|
| Сахар | 66 г | 66 г |
| Мука | 54 г | 47 г |
| Какао | — | 16 г |
| Масло растительное | 36 г | 36 г |
| Вода | 28 г | 28 г |
| Сода | 0,7 г | 0,7 г |
| Лимонная кислота | 0,7 г | 0,7 г |

Базовый рецепт: 560 г яиц → 370 г сахара, 300 г муки, 200 г масла, 155 г воды,
1 ч. л. соды без горки, 1 ч. л. лимонной кислоты, щепотка соли.

## Технология

Один HTML-файл без зависимостей: HTML + CSS + vanilla JS. Работает офлайн,
адаптирован под телефон.
